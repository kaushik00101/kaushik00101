# Minimal GitHub profile setup

This version intentionally keeps the profile quiet so your repositories remain the focus.

## Included
- `README.md` — a restrained anime/nature-inspired profile with a muted sage accent.
- No contribution snake, trophy wall, visitor counter, large banner, or excessive badges.

## Install
1. Open `https://github.com/kaushik00101/kaushik00101`.
2. Edit the repository's `README.md` or upload this replacement.
3. Commit the change.
4. Refresh `https://github.com/kaushik00101`.

## Notes
- Replace the project links with exact repository URLs if your repository names differ.
- The technology icons and GitHub stats are remotely hosted widgets.
- Your actual GitHub avatar is managed separately in GitHub profile settings.
